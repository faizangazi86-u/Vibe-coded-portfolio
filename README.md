## 🚀 What is "Vibe Coding"?
Vibe coding is building software by describing the desired outcome, style, and feel in natural language and letting an AI assistant generate and refine the code — focusing on creative direction and iteration speed rather than manual syntax. This project was created that way, using Claude to draft, style, and polish the site through conversational prompts.

## 📂 Getting Started

### Run locally
```bash
git clone https://github.com/faizangazi86-u/<your-repo-name>.git
cd <your-repo-name>
```
Then just open `index.html` in your browser — no build step or dependencies required.

### Deploy with GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Set the source branch to `main` (root folder).
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.
